# DustStrike

Локальный тактический FPS для Windows, Linux и macOS. Игра запускается отдельным приложением и работает офлайн с ботами. Godot и Blender для игры устанавливать не нужно.

**[Скачать игру или поделиться ссылкой](https://github.com/keeper27069/DustStrike/releases/latest)** · [Исходный код](https://github.com/keeper27069/DustStrike)

## Скачать и запустить

На странице релиза откройте **Assets**, скачайте архив для своей системы и полностью распакуйте его. Архивы первого выпуска **v0.1.0**:

| Система | Архив | Запуск после распаковки |
|---|---|---|
| Windows, x86_64 | `DustStrike-v0.1.0-Windows-x86_64.zip` | Откройте `DustStrike.exe`. |
| Linux, x86_64 | `DustStrike-v0.1.0-Linux-x86_64.tar.gz` | В папке игры выполните `./DustStrike.x86_64`. Если нет права на запуск, сначала выполните `chmod +x DustStrike.x86_64`. |
| macOS 12+, Intel и Apple Silicon | `DustStrike-v0.1.0-macOS-universal.zip` | Откройте `DustStrike.app`. |

Сохраняйте файлы из архива вместе. В главном меню выберите CT или T и нажмите «Начать операцию». Для игры нужны клавиатура и мышь; на Mac можно использовать трекпад.

У сборки macOS локальная подпись ad hoc, без нотариального заверения Apple; у сборки Windows нет подписи издателя. При первом открытии система может показать предупреждение о неизвестном разработчике.

На Mac после первой попытки запуска можно разрешить открытие этой сборки в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если вы доверяете источнику. [Инструкция Apple](https://support.apple.com/en-gb/102445).

Это настольная игра: ссылка ведёт на скачивание, запуск в браузере и сетевая игра не предусмотрены.

В игре: 5 × 5 с девятью ботами, классическая планировка Dust II, две точки закладки, раунды до шести побед, экономика, броня, закупка, 34 вида огнестрельного оружия, нож, Zeus x27, пять видов гранат и бомба. По умолчанию включена тренировка: весь арсенал доступен без ограничений. Кнопка режима включает классическую экономику и ограничения команд.

Это самостоятельный играбельный прототип. Планировка карты основана на классической Dust II, а не на современной карте из CS2. Графика, анимация и физика упрощены; численная оценка визуального сходства в 70% не подтверждена. Сетевого мультиплеера, матчмейкинга и точной симуляции Source 2 здесь нет.

## Управление

| Действие | Клавиши |
|---|---|
| Движение, обзор | WASD, мышь |
| Стрельба | Левая кнопка мыши |
| Прицел / дополнительный режим оружия | Правая кнопка мыши |
| Перезарядка | R |
| Тихий шаг, приседание, прыжок | Shift, Ctrl / C, пробел |
| Основное оружие, пистолет, нож | 1, 2, 3 |
| Выбор гранаты, бросок | 4, G |
| Zeus, если куплен | 5 |
| Закупка | B |
| Установка / обезвреживание бомбы | Удерживать E стоя на месте |
| Осмотр оружия | F |
| Таблица счёта | Tab |
| Наблюдение после смерти: следующий / предыдущий союзник | Стрелки → / ←; пробел / Shift+пробел; ЛКМ / ПКМ или колесо мыши |
| Пауза | Esc |
| Полный экран | F11 |

За T бомба находится у игрока. Установка на A или B занимает 3,2 секунды; взрыв происходит через 40 секунд. CT обезвреживает за 10 секунд или за 5 секунд с набором сапёра. Если игрок играет за CT, бомбу несёт бот атаки. После смерти носителя её можно подобрать.

Снайперские винтовки, AUG и SG 553 имеют увеличение. Glock-18 и FAMAS переключают очередь по три выстрела. Для USP-S и M4A1-S дополнительный режим меняет звук глушителя; отдельной анимации его снятия пока нет. Zeus перезаряжается автоматически за 30 секунд. Характеристики оружия приблизительные.

После смерти камера на 3 секунды остаётся на месте гибели. Появляется карточка с именем и командой убившего, его оставшимся здоровьем и отметкой попадания в голову, если оно было. Затем камера переходит к живому союзнику от первого лица через короткое затемнение. Пробел позволяет перейти раньше; первые 0,75 секунды и удерживаемые кнопки не пропускают карточку случайно. Пауза останавливает отсчёт. Собственный урон, огонь по своим и урон окружения подписываются отдельно.

При наблюдении внизу показаны имя, здоровье и броня союзника. На Mac также работают Control+клик для предыдущего союзника и вторичный клик трекпада. Можно переключать союзников; если наблюдаемый погибает, камера выбирает следующего живого. В новом раунде управление возвращается игроку.

Качание камеры и оружия при ходьбе отключено; подъём камеры на ступенях сглажен. Для каждого бойца выбирается отдельное свободное место появления на полу. В ленте убийств стрелявший указан слева, погибший справа: CT выделены голубым, T — золотым, рядом с каждым именем написана команда. Урон гранатой по своим и самоликвидация отмечаются отдельно.

Боты идут по склонам без искусственных подбрасываний. Высота подъёма на небольшую ступень определяется по её поверхности; при застревании бот перестраивает маршрут и пробует обойти препятствие.

Задержка срабатывания после броска: осколочная граната — 3,5 с, световая и ложная — 3 с, дымовая — 4 с, зажигательная — 2,5 с.

Персонажи CT и T используют анатомическую модель человека, отдельную одежду, бронежилеты, перчатки, ботинки и узнаваемое снаряжение команд. CT носит шлем с гарнитурой и защитными очками, T — вязаную шапку и шейный платок. Скелет управляет стойкой, бегом, прицеливанием, отдачей, перезарядкой и падением после смерти. Это игровые модели с упрощёнными материалами, а не фотореалистичные сканы в готовом снаряжении.

## Исходники

`project.godot` открывается в Godot 4.5.1. `scripts/` содержит игру, управление, ботов и интерфейс. `assets/` — модели, материалы и предварительно построенную навигацию. `source_art/` — созданные Blender-модели и скрипт их генерации, включая дополнительный авторский вариант песчаной карты. Он сохранён как исходник; игровой уровень по умолчанию использует классическую Dust II.

Редактируемые персонажи: `source_art/operator_ct.blend` и `source_art/operator_t.blend`. Скрипт `source_art/build_operators.py` создаёт одежду, снаряжение, материалы, скелет и анимации, экспортируя игровые GLB. Для повторной сборки ему передаётся путь к `human_base_meshes_bundle.blend` из указанного ниже исходного набора Blender Studio.

### Сборка из исходников

Для экспорта установите **Godot 4.5.1 Standard** и шаблоны экспорта **4.5.1** через меню Godot «Редактор → Управление шаблонами экспорта». Blender для сборки игры не требуется: готовые GLB и текстуры уже включены в репозиторий. Blender нужен только для редактирования и повторного создания моделей.

Скачайте исходники или клонируйте репозиторий. В корневой папке проекта выполните команды ниже в терминале с доступной командой `godot` (при необходимости замените её полным путём к установленному Godot):

```sh
git clone https://github.com/keeper27069/DustStrike.git
cd DustStrike
godot --headless --path . --editor --import
mkdir -p exports/windows exports/linux exports/macos
godot --headless --path . --export-release "Windows Desktop" exports/windows/DustStrike.exe
godot --headless --path . --export-release "Linux" exports/linux/DustStrike.x86_64
godot --headless --path . --export-release "macOS" exports/macos/DustStrike.zip
```

Команды рассчитаны на shell Linux/macOS. В Windows создайте те же папки любым удобным способом и используйте путь к исполняемому файлу Godot. Те же три профиля доступны в окне Godot «Проект → Экспорт»: `Windows Desktop`, `Linux`, `macOS`. Для подписи macOS тем же способом, что в опубликованной сборке, выполняйте экспорт на Mac.

При изменении профилей оставляйте экспорт всех ресурсов: часть моделей загружается по имени во время игры. В фильтре дополнительных файлов обязательно сохраните **`*.json`** — без `assets/weapons.json` игра не сможет загрузить арсенал. В сборку также должны входить `assets/collision.json`, `assets/dust_navigation.tres` и файлы атрибуции. Папку `.godot/` Godot создаёт при импорте; в исходный репозиторий она не включается.
